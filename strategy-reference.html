## Rules
| | 2c7c (default) | R5s (previous) |
|---|---|---|
| Universe | Watchlist: a symbol joins the first day it passes the screen and never leaves (`watchlist` table) | Today's screener hits plus open positions |
| Entry gate | Pivot (Day F), liquid, RS percentile ≥ 90 vs the S&P 1500 + watchlist pool, and pool breadth ≥ 10% (`signals/pool_gate.py`) | Pivot, liquid |
| Initial SL | Signal close × (1 − clamp(3.5 × ATR14 / close, 4%, 20%)), fixed at the signal | Fill × (1 − clamp(3.5 × ATR14 / fill, 16%, 40%)) |
| 15% rule | Buy only if (price − SL) / price ≤ 15%. Otherwise place a limit at SL / 0.85, capped by the earnings-gap band (R × 2), and fill at min(open, limit). Cancel when the open is at or below the SL, when the close is below the Day C close, or when a newer pattern replaces it | Earnings-gap band wait only |
| Trailing stop | Every new pivot raises it to Day C low × (1 − clamp(1 × ATR14 / low, 0.5%, 20%)). It is never lowered | 3.75× / 12% / 45% |
| TP | One fixed price per cycle, set by the cycle's first signal: +15% / +50% / +200% by close/POC tier (cuts 1.25 / 2.25). Sell 25% there (`TP1` event); the rest rides the trailing stop with no TP | Full exit at +25% / +150% / +2000% of entry |
| Time stop | 45 bars, exit at the close if still below −1%. No second stage | 30 bars / −1%, then 60 bars / +8% |
| Pyramiding | At most 5 positions per symbol; a pending limit counts toward the 5 | Unlimited |
| Sizing | One shared THB 350k pool. Each entry: min(5% NAV / stop distance, 20% NAV). Skip when free cash is under 50% of that target. Same-day entries are funded in RS order | 35 sleeves × 10,000 THB |
| Same bar | open ≥ TP → TP at the open; open ≤ stop → stop at the open; low ≤ stop → stop (taken before the TP); high ≥ TP → TP | — |

## What changed in the code
- **State machine and model:**
  - `signals/state_machine.py`: `DEFAULT_MODEL = "2c7c"`, `Position.advance_2c7c`, `SymbolPosition._update_2c7c`, the `TP1` partial event, `PositionEvent.stop_price` / `quantity_fraction`, and `position_target_price()` for displays.
  - `signals/watchlist_v2.py`: the model constants.
  - `signals/pool_gate.py`: the RS and breadth gate.
- **Database:** `db/migrations.py` migration `20261113_2c7c_default` adds the position columns, `symbol_meta.cycle_tp_price` and the `watchlist` table. `db/database.py` persists them. P&L blends the 25% TP1 (only for TP1 rows on or after 2026-11-13).
- **Pipeline:**
  - Updates the watchlist; the first run seeds it from screener_hits.
  - Builds the pool gate every run. If the gate is unavailable, there are no new entries and the run reports a `pool_gate` stage issue.
  - Passes `high` and `entry_gate` per bar, and sends RS priority to the execution bridge.
  - `POOL_GATE=0` is for tests and development only.
- **Sizing and portfolio:**
  - `portfolio/signal_execution.py`: shared-pool sizing by default (`WEBULL_SIZING=fixed_notional` restores the legacy sleeves), funding in RS order, and TP1 selling 25% of the slot's filled quantity.
  - `portfolio/default_model.py`: a new model book, "Default Strategy Model 2c7c (THB 350k / shared pool)". The R5s-era book stays in the DB as history.
  - `portfolio/execution_setup.py`: no sleeves by default.
  - **No execution switch was enabled and no order was sent.**
- **Displays:** digest, dashboard and Discord/bot show the fixed cycle TP ("trail only" after the 25%). Forward tracking starts at the 2026-11-13 bar against `data/default-2c7c-20261113/reference.json`. The shadow test (R5s vs S0) is labelled legacy.
- **TradingView:** `tradingview/watchlist_v2_2c7c.pine` is the default chart script. `atr_stop_loss.pine`, its merged copy, `poc_tier_levels.pine` and `poc_sl_trailing_20_symbols.pine` are marked LEGACY (R5s).
- **Backtest:** the default backtest is now `backtest/watchlist_portfolio.py`. `backtest/strategy.py` / `run_backtest.py` remain the R5s engine.
- **Held positions:** `scripts/convert_positions_2c7c.py` does a dry run first, then `--apply` (DB backup plus an alert per position).
